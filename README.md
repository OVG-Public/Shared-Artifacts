## Before using the AI skills

A skill is an instruction file for AI assistants that support skills (for example, Claude). To use one, download the `.md` file and add it to your AI tool as a skill. Before running a skill on real material:

- **Check your organization's AI and data policy.** Interview transcripts and finance data are often confidential.
- **Use an approved tool.** Run skills only in an AI environment cleared for that data.
- **Get consent.** Tell interviewees their sessions will be recorded or transcribed and processed with AI, as your policies and local law require.
- **Treat outputs as drafts.** A person reviews them and decides what is true and what is shared.
